# Driving VLA rivals: NAVSIM v1 navtest PDMS by stage (checked 2026-11-26)

Every number below was read in the paper's own arXiv HTML (latest version, with earlier versions compared where they differ). PDMS means NAVSIM v1 PDMS on navtest unless a cell says EPDMS (NAVSIM v2 metrics).
**V** = read in the paper's own table or text. **R** = not from the paper. Here R only marks ReCogDrive's model sizes, which come from the authors' public GitHub README (I read the raw file myself). No number comes from a search snippet.
"No extras" means one sample, with no best-of-N, no selection or scorer, no reflection or refinement pass, no CFG, no ensemble and no test-time anchors.

## Corrections and additions to the earlier notes (one line each)

1. ReCogDrive: 86.8 → 89.6 (v1) and 86.5 → 90.8 (v2) confirmed (V). The paper never says which size gives v2's 90.8; the authors' README lists it as the 2B model, and the 8B RL model scores 90.4 (R).
2. ReCogDrive: the plain SFT baseline (trajectories only, no QA pretraining, no planner) is 82.4 in v2 Table 3 (the v2 text says 83.3), and 83.3 in v1.
3. DriveFine: 90.8 (Tab. 4), 90.7 (Tab. 1) and 90.5 (Tab. 5) all include a built-in self-refinement pass by an RL-trained refinement expert. After GRPO alone, one pass with no refinement scores 89.6.
4. DriveFine: there are higher variants not in the notes. 91.8 (Tab. 1; text says 91.9) adds an extra trained scorer, and 94.2 is best-of-6.
5. WAM-Diff: "82.3 strict SFT" already includes the reverse-causal decoding order. With nothing added the model scores 80.3 (Tab. 5; text says 80.2).
6. WAM-Diff: 86.6 also includes VQA co-training, and 91.0 keeps CFG on, so no after-RL number without guidance exists ("not reported").
7. WAM-Diff2: it is a 2B model with no RL. 88.3 and 91.1 come from the task-specific NAVSIM model; the unified multi-task checkpoint scores 87.44 and 91.05. The autoregressive baseline is 88.1.
8. AutoVLA: 80.54 and 89.11 confirmed. The same table also has 92.12 (best-of-6 with an oracle scorer). The 89.11 is the "best-performing" RFT checkpoint, and the paper does not say which data that choice used.
9. SpanVLA: 82.1 and 90.8 are from v2 (Oct 2026). v1 (Apr 2026) reported 90.3 after RL. v2 adds 93.3 (best-of-6, oracle).
10. Curious-VLA: 87.6 has no test-time extras. It is the best SFT with training-side additions (data expansion, CoT, step-wise normalization). 90.3 is both the after-RL single-sample number and the headline; the top table number is 94.8 (best-of-6).
11. AdaThinkDrive: 83.3, 86.2, 87.5 and 90.3 confirmed. 90.3 is one sample after GRPO with no extras. The table also has 93.0 (best-of-4 picked by the NAVSIM evaluator).
12. DriveVLA-W0: 85.6, 88.4 and 90.2 with no RL confirmed. 90.2's anchor method is only described as "following Hydra-MDP". 93.0 is best-of-6. The v1 main table showed only 90.2 and 93.0.
13. ReflectDrive: 84.8 is not the bare model; CFG is already on at inference. 91.1 adds rule-based scoring and regeneration at test time. 94.7 uses ground-truth agents.

## Other checks worth knowing before quoting

- Curious-VLA Tables 4 and 10 report "mean-PDMS" of 90.7–91.6. These are measured on a navtrain subset, not navtest, so do not quote them as navtest.
- WAM-Diff Table 5 rows 1 and 2 have identical sub-scores but different PDMS (80.3 vs 82.3). Row 2 matches Table 8.
- ReCogDrive's EPDMS row (83.6) is unchanged from v1 to v2, so it may not have been re-measured for the v2 model.
- WAM-Diff2's appendix says it trained on the "Navtest training split" of 103,288 samples. That count is navtrain's, so this looks like a typo.
- The DriveVLA-W0 public release ships only the flow-matching checkpoint (README: PDMS 87.2). The 90.2 anchor variant has no public description beyond the paper.
